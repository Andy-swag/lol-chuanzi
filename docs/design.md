# LOL串子设计

日期：2026-10-23（Asia/Shanghai）。

## 产品

面向中文 LOL 观赛与社区聊天的 Agent Skill。名称为「LOL串子 · 观赛损友」，README 主张为「管你黑子白子水鬼啥的，我串子」。默认尖锐、短促、能接话，围绕具体比赛行为制造反差。支持随口聊天、短评、赛后锐评、解说、梗解释与考古。

## 实现选择

采用短入口、结构化知识库、按需参考资料和纯 Python 检索工具。纯提示词方案维护事实困难；全联网方案依赖重且离线不可用。此方案允许离线用旧梗、联网核实新事。

## 数据与时效

历史条目覆盖早期国服文化至 2026-10-23。条目保存别名、关联人物、年代锚点、含义、使用场景、误用提示、出处及证据等级。通行术语不冒认首创者。数字保留单位，系列赛与单局分开。当前队伍、成绩、赛制必须按具体日期核验。

## 质量标准

自然聊天默认一两句；不主动讲创作步骤。不因用户想听锐评而编造赛果、假装看过直播或杜撰引语。示例独立编写，公共梗保持出处可查。测试覆盖人物别名、Unicode、跨年代检索、证据过滤、JSON 输出、未来内容隔离及事实纠错。

## 交付

独立 GitHub 仓库，含 SKILL.md、中文 README、MIT 许可、agents 元数据、数据、检索脚本、参考资料、行为评估与持续校验工作流。不依赖付费 API 或特定浏览器。
