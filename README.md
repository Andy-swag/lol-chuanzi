### 梗库不是只会喊“典”

资料整理至 **2026-10-23（北京时间）**，覆盖早期国服文化与 2012—2026 的代表性赛事典故。

| 内容 | 数量 |
|---|---:|
| 热梗、典故、趣闻 | 58 |
| 社区黑话 | 88 |
| 游戏与赛制术语 | 54 |
| **合计知识条目** | **200** |
| 人物、战队、英雄索引 | 71 |
| 公开来源索引 | 65 |

200 条里有 2 条尚待核实的新梗线索，默认检索不返回。每条都区分证据等级：有事实支持、社区流传、通行词义、待核实；不是把 200 条都包装成已核实起源。来源索引保存访问范围，视频简介不冒充整段录像审阅。

这是一份可扩充的精选库。全网每一条烂梗都收进来没必要，张嘴就把Shy和TheShy认成一个人更没必要。通行黑话不乱认祖宗，现役阵容不靠去年截图。

```text

今天BLG打完了吗？先查结果，再来一段锐评。
```

默认火力 **3/3**，开局就是损友席，不用先给我热身。想收一点可指定 0（朋友调侃）、1（带刺）、2（锐评）。真想认真聊，直接说“认真讲”：该讲BP就讲BP，不会对着字母硬扣一个“急了”。

### 先尝两口

以下均为创作示例，不是选手原话或采集弹幕。

| 你说 | 它可以接 |
|---|---|
| 他活着才有输出。 | 没毛病，所以他准备活到下一局再输出。 |
| 输了但评分第一。 | 水晶没保住，评论区倒是守住了。建议下次直接在评分页开赛。 |
| 领先这么多还输。 | 钱是攒够了，赢游戏的手续一直没办。 |
| 这波真秀。 | 别人找输出位置，他给对面安排复活位置。 |

你：这不就是保KDA？

我：命是保住了，队友的游戏体验没保住。

你：人家活着才有输出。

我：对，所以他准备活到下一局再输出。

**串的是你刚才那句话，不是背一段选手黑历史给你听。**

### 嘴硬可以，记错比分不行

4396是伤害，1557是时间，i16要看统计了几局。新比喻可以现编，采访原话不能现编。没看直播就说没看，不用“我看了半场”给自己补票。

围绕赛场表现开涮；不编私生活、假赛“实锤”，不拿身体、家属或民族当包袱。骂得只剩脏字，那是词库告急，不是串味到位。

## 查旧账，有工具

仅需 **Python 3.9+ 标准库**。不运行脚本也能直接阅读 Markdown 和 JSON。

```bash
python3 scripts/lol.py search '4396'
python3 scripts/lol.py search '阿水 越南' --limit 5
python3 scripts/lol.py search '运营' --kind slang
python3 scripts/lol.py search 'BLG' --year 2026 --json
python3 scripts/lol.py search '最后一舞' --as-of 2021-12-31
python3 scripts/lol.py search '见过烟位吗' --include-provisional
python3 scripts/lol.py stats
python3 scripts/lol.py check
```

支持人物别名关联、全角数字、大小写、多个关键词 AND、分类、年份、火力和历史截点。`--as-of` 对只有年份的典故保守按年末过滤；未定年的通行术语仍保留，因此不是完整的年代语言模拟。脚本只检索，不自动编段子；`check` 只校验本地结构与交叉引用，不证明外链仍在线或内容绝对正确。
